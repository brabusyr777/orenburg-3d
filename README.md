# Оренбург 3D

Интерактивная 3D-модель Оренбурга в браузере: ~65 тыс. зданий, реки, рельеф, значки достопримечательностей (200+ мест), поиск по местам и улицам, карточки мест с фото, временем работы и кнопкой «Построить маршрут» (2ГИС, Яндекс Карты, OpenStreetMap). Режимы день, вечер, ночь, лёгкий режим для слабых устройств, управление камерой как в картах (жесты на телефоне).

Учебный и портфолио-проект, некоммерческий. Стек: JavaScript, three.js, данные OpenStreetMap, Python (подготовка данных).

## Как устроено
- `index.html`: вся страница в одном файле (данные города упакованы внутрь, около 7,5 МБ).
- `lib/`: three.js r128, OrbitControls, pako.
- `photos/`: фото с открытыми лицензиями (авторы на странице `about.html`).
- `about.html`: о проекте, лицензии, авторы фото.
